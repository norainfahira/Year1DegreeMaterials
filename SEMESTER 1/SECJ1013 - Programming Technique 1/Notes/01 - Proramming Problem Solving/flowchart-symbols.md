# Flowchart Symbols Quick Reference

| Symbol | Name | Description |
|--------|------|-------------|
| ⭕ | **Terminal** | Start or end of a program. Only one Start and one Stop per program. |
| ▭ | **Process** | Data manipulation (calculations, assignments). One flowline in, one out. |
| ▱ | **Input/Output** | Reading data (input) or displaying data (output). One in, one out. |
| ◇ | **Decision** | Yes/No or True/False condition. One flowline in, two flowlines out. |
| 🟦 (Rectangle with lines) | **Function/Subroutine** | A separate module or function. One in, one out. |
| ⚪ (Circle) | **On-page Connector** | Connects remote parts of flowchart on same page. |
| 🏠 (Pentagon) | **Off-page Connector** | Connects flowchart across different pages. |
| ➡️ | **Flowline/Arrow** | Indicates the direction of flow. |
| 💬 | **Comment** | Adds descriptions or clarifications. |
